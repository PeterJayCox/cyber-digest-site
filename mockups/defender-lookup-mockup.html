Defender lookup·CVE → ATT&CK → D3FEND

Pick a vulnerability the digest has covered; this shows how attackers are using it, then the MITRE D3FEND countermeasures that answer those techniques — grouped by what you would actually do (harden, isolate, detect, respond). The offensive half of the story already exists in the CVE × MITRE ATT&CK matrix; this is the defender's half.

Provenance & method (what is measured, what is inferred)

  • Measured from the Cyber Digest DB: 216 CVEs, 145 with ATT&CK mappings, 60 with D3FEND countermeasures, 4,113 technique→countermeasure edges across 271 D3FEND techniques.
  • Inferred (analyst judgement, confidence-rated): the CVE→technique mapping. Each CVE's rationale is shown on the technique strip, with the confidence the wiki note records (high / medium / low).
  • Framework versions: MITRE ATT&CK v19.2 · MITRE D3FEND countermeasures via the wiki's own mapping tables.
  • An uncovered technique is not a safe technique. It means the mapping carries no countermeasure for it — the gaps are listed openly on the coverage view rather than hidden.
  • Known limitation: this page cannot yet link a CVE to the digest story that reported it — the Story DB's cve_id column is empty for all 1,012 stories, so CVE→story linkage would need an ingest change first.
