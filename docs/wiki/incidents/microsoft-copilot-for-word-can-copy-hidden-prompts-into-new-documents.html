Microsoft Copilot for Word Can Copy Hidden Prompts Into New Documents

Summary

Security researcher Håkon Måløy disclosed that hidden instructions in a Word document can make Microsoft 365 Copilot rewrite figures in a report and then copy the same instructions into the finished file. Microsoft confirmed the behaviour on March 31 and deployed two mitigations — blocking the original prompt wording and upgrading the underlying model to GPT-5.5 — but Måløy demonstrated the full chain still works with modified instructions on GPT-5.6. The vulnerability class remains exploitable at time of publication.
