CISA Publishes Open Source Software Security Principles and Practices

Summary

CISA released a new publication titled "Open Source Software: Security Principles and Practices", providing guidance on secure development, maintenance, and consumption of open-source software — a timely resource given the concurrent focus on supply-chain attacks and the recent npm hijack by North Korean Sapphire Sleet.
