TriWest Healthcare Alliance Breach

Field Value
Type Incident — Healthcare Data Breach
Date 2026-07-22
Status Confirmed
Sources HIPAA Journal

Summary

TriWest Healthcare Alliance disclosed a data breach impacting approximately 12,000 Tricare military health system beneficiaries.

Key Details

  • Data breaches also announced by Texas Medicaid and Healthcare Partnership and the Minnesota Health Insurance Network in the same reporting period
  • Affects US military healthcare beneficiaries (Tricare system)
  • Type of data exposed not yet fully detailed

Significance

Highlights continuing vulnerability of healthcare data systems, particularly those serving military personnel. Part of a pattern of multiple healthcare data disclosures in July 2026.
