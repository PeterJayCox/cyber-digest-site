NVIDIA Forms 37-Member Open Secure AI Alliance, Open-Sources NOOA Framework

Summary

NVIDIA and 36 other organisations launched the Open Secure AI Alliance to develop open technoLogies for securing AI agents. NVIDIA also open-sourced NOOA (NVIDIA-labs OO Agents), an Apache 2.0 framework for testing, tracing, auditing, and governing AI agent behaviour.

Key Details

Field Detail
Lead NVIDIA
Members 37 organisations
Framework NOOA (NVIDIA-labs OO Agents)
License Apache 2.0
Date 2026-07-27

Notable Members

Microsoft, Cisco, Cloudflare, CrowdStrike, Hugging Face, IBM, Palo Alto Networks, Red Hat, Linux Foundation, and others.

Scope

The alliance's technical scope covers:

  • Identity — Agent authentication and authorisation
  • Permissions — Access control for AI agents
  • Isolation — Sandboxing and containment
  • Guardrails — Behavioural constraints and safety
  • Logging — Audit trails for agent actions
  • Model formats — Standardised security metadata
  • Multi-model scanning — Vulnerability assessment across model types
  • Secure coding workflows — AI-assisted secure development
