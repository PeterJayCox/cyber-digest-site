💻 IT / Technology

1. WordPress wp2shell Exploitation Grows as Public Exploit Fuels Mass Scanning - Summary: Attackers are actively exploiting two chained critical WordPress vulnerabilities (CVE-2026-63030, CVE-2026-60137) — codenamed wp2shell — enabling unauthenticated remote code execution. Telemetry from KEVIntel shows 13 unique IP addresses from Switzerland, Germany, the UK, Indonesia, Lithuania, the Netherlands, and Singapore conducting mass scanning. Public exploit code was released early Saturday, with credential exfiltration and RCE following rapidly. - Source: The Hacker News - Reliability: Tier 2/4 — High - Date: 2026-07-21

2. New ENCFORGE Ransomware Targets AI Model Files in Langflow RCE Attack - Summary: Sysdig researchers linked a second attack on the same Langflow server to the JADEPUFFER AI-agent-driven operator. The operator now deploys ENCFORGE, a compiled Go ransomware designed to encrypt model weights, vector indexes, training datasets, and other AI infrastructure files. Entry point remains CVE-2025-3248 (CVSS 9.8), in CISA's KEV catalog since May 2025. - Source: The Hacker News - Reliability: Tier 2/4 — High - Date: 2026-07-21

3. Critical ServiceNow AI Platform Flaw Exploited for Unauthenticated Code Execution - Summary: Threat actors are actively exploiting CVE-2026-6875 (CVSS 9.5), a sandbox escape vulnerability in the ServiceNow AI Platform. Patches were released throughout June across multiple versions. ServiceNow is restricting the type of code that can run in sandbox contexts to enhance security. - Source: The Hacker News - Reliability: Tier 2/4 — High - Date: 2026-07-21

4. FakeGit Campaign Uses 7,600 GitHub Repositories to Spread SmartLoader Malware - Summary: Researchers at Island discovered nearly 7,600 malicious GitHub repositories — over 800 posing as AI skills or MCP servers — delivering SmartLoader malware. The campaign uses copied projects, lookalike developer profiles, and convincing READMEs. SmartLoader establishes persistence and delivers StealC info-stealer as a secondary payload. - Source: The Hacker News - Reliability: Tier 2/4 — High - Date: 2026-07-20

5. Exposed Server Reveals AI-Assisted Phishing Toolkit Behind WebDAV Malware Campaign - Summary: Rapid7 discovered an open delivery server containing 1,048 files of a malware operator's development toolkit — lure templates, droppers, builder notes, and two campaign chains. One live campaign targeted Windows users in Mexico via a fake government ID-lookup site over WebDAV exploiting CVE-2025-33053. Evidence suggests generative AI was used to produce, test, and document the phishing delivery infrastructure. - Source: The Hacker News - Reliability: Tier 2/4 — High - Date: 2026-07-20
