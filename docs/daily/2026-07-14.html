1. Compromised jscrambler 8.14.0 npm Release Drops Rust Infostealer During Install

Socket Security flagged the malicious release six minutes after publication. The payload (7.8MB) contained three gzip-compressed native binaries targeting all three platforms.
  • Source: The Hacker News
  • Reliability: Tier 2/4 — High

2. Google and Microsoft Pull ModHeader With 1.6 Million Installs After Dormant Collector Found

  • Summary: A hidden browsing-history collector was discovered in the official ModHeader browser extension on both Chrome and Edge Web Stores (1.6M combined installs). The collector was dormant — an empty allowlist kept it from activating — but analysis confirmed it shipped inside the genuine signed extension, not a counterfeit. Microsoft pulled the listing July 3; Google followed July 10.
  • Source: The Hacker News
  • Reliability: Tier 2/4 — High
  • Date: 2026-07-13

3. CrashStealer macOS Malware Uses Notarized Dropper to Pass Gatekeeper Checks
